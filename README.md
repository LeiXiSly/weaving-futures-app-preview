# Weaving Futures — app preview

A static, clickable English-language prototype for the Weaving Futures exhibition guide. It includes collection search, work details, an exhibition map, workshop booking, a personal visit area, and an illustrative AR navigation journey.

Open `index.html` to preview locally. The site uses relative paths and can be published directly from the repository root with GitHub Pages; no build command is needed.

The venue and artwork visuals are concept/design renders. Booking, sign-in, and AR tracking are prototype interactions rather than live services.
